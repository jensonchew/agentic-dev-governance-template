# Framework Review

Use this skill to sanity-check framework-level changes before merge.

## When to use

- A governance doc changes
- A new reusable skill is added or updated
- A workflow or checklist changes
- A repo-wide convention changes

## Review questions

- Does the change stay framework-agnostic?
- Does it improve reuse, clarity, or safety?
- Does it avoid hidden stack assumptions?
- Does it fit the repo's charter split and governance model?
- Is it discoverable from the core context files?

## Output

- Pass / revise recommendation
- Short list of reasons
- Any follow-up docs that should be updated
